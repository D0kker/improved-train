# Plantilla de cierre de sesión

Usa esta estructura para mantener `docs/PROJECT_CONTEXT.md` después de trabajo relevante:

```md
Última actualización: YYYY-MM-DD

## Qué quedó funcionando
- Resultado observable y archivos principales.

## Alcance que no se implementó
- Límites explícitos para evitar asumir trabajo inexistente.

## Decisiones tomadas
- Decisión y motivo; si es duradera, agregarla a `docs/DECISIONS.md`.

## Validación realizada
- Comandos y resultados relevantes, incluyendo arquitectura probada.

## Próximo paso recomendado
- Una acción concreta y acotada.

## Preguntas o bloqueos
- Información o dependencia externa pendiente.
```

No incluyas secretos, PUUIDs o Riot IDs de usuarios reales, respuestas crudas de Riot, transcripciones extensas ni hipótesis presentadas como hechos.
